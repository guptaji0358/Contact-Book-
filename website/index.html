    Two ways to actually dial

    The app never claims to be a phone. It just knows two ways to reach one.

    Mode 01

    Hand off to Phone Link

    Contact Book sends the number to whatever app Windows has registered for tel: links — usually Microsoft Phone Link, once it's linked to your Android phone. The call happens on your phone; this window just placed the request, minimized, without stealing focus.

    Mode 02

    Direct LAN voice

    Give a contact a Device IP and Contact Book will ring that device directly over your local network — no phone, no carrier, no internet required. Useful for two desks running the same app on the same Wi-Fi.

    Localonly
    no cloud sync
    From the installer's own agreement page

    A rough book, kept honestly.

    Every contact you add lives in a SQLite file next to the app. Nothing is uploaded, synced, or shared with a server — the installer says this outright, in a License & Data Agreement page you have to read and accept before setup continues.

    And because it's a rough book and not a telephone, real calls still need a real line: set up Phone Link, or give a contact a Device IP for LAN calling. Contact Book is honest about which one you're getting before you press call.
